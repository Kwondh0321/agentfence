# Code of Conduct

[한국어](CODE_OF_CONDUCT.md) | English

We want everyone to be able to participate safely. Treat others with respect, assume good intent, focus criticism on ideas and code rather than people, and protect contributors' personal information.

Harassment, threats, discriminatory language, unwanted sexual attention, deliberate intimidation, and publishing another person's private information are unacceptable. These expectations apply in repository issues, pull requests, reviews, and other project spaces.

Maintainers may edit or remove harmful content and temporarily or permanently restrict participation when necessary to protect a safe, productive community. Report conduct concerns to the repository maintainer through GitHub; request a private channel when a public report would expose sensitive information.
