# Security Policy

[한국어](SECURITY.md) | English

Report suspected vulnerabilities through this repository's private GitHub Security Advisory feature. Do not disclose an unpatched vulnerability in a public issue.

Include affected versions, minimal reproduction steps, expected impact, and any known mitigation. Valid reports will be acknowledged and a disclosure timeline will be coordinated before publication. Please do not include real credentials, personal data, or confidential customer material in a report.
